# 小鼠抬头检测 · 比赛优化工具包

本目录包含为参赛做的三类优化产出：**统一检测流水线**、**实验结果（消融/组间/一致性）**、**PPT 比赛版生成脚本**。

## 一、统一检测流水线 `headlift.py`

整合了项目里 7 个散落脚本，修复了已发现的 bug，命令行直接可用：

```bash
python headlift.py --csv "../video/1631 PBSDLC_resnet50_..._15000.csv" --video "../video/1631 PBS.WMV"
# 加 --clips 自动按时间戳裁剪抬头片段；--mode fixed --fixed-offset 20 切固定阈值
```

核心设计（可作为答辩时"方法"一句话说明）：

1. **特征**：头部俯仰角 = 头顶→鼻子向量角（抬头时角度下降）；置信度 <0.6 的帧线性插值，默认 5 帧滑动中值滤波抑制逐帧抖动。
2. **判定**：动态阈值 = 视频中位数 − 1.5σ（每段视频自适应，免手调）；幅度过滤（≥中位数到 5 分位距离的 20%）；状态机要求"从平视抬起"且回到中性区才计下一次；最短持续 0.15s（按帧率自动换算帧数）。
3. **输出**：逐事件表（起止帧/秒、时长、抬升深度）+ 行为学指标（次数、次/分钟、总时长、平均/中位时长、首次抬头潜伏期）。

> ⚠️ 重要发现：原 `final_analyze.py`（"论文级算法"）读 CSV 列错位——把帧序号当坐标、把似然值当坐标，其输出不可用；`generate_custom_video_gui.py` 的 y 规则列位正确。本流水线按 `(bodypart, coord)` 显式取列，从根源杜绝错位。

## 二、实验结果 `results/`（可直接放进申报书/PPT）

`run_experiments.py` 在 4 只鼠（1631/1632 PBS，1635/1637 CNO，各约 5 分钟视频）上运行：

| 文件 | 内容 | 关键结论 |
|---|---|---|
| `消融对比_方法x小鼠.csv` | 5 种方法 × 4 只鼠的完整指标 | 固定阈值 ±10° 手调变化最多使计数变化 27% |
| `方法稳健性_跨小鼠CV.csv` | 各方法跨小鼠变异系数 | **动态阈值 CV 0.35–0.41 vs 固定阈值 0.55–0.59**（核心卖点） |
| `图1_方法消融对比.png` | 阈值敏感性柱状图 | 固定阈值波动大，动态阈值稳定 |
| `图2_俯仰角轨迹_*.png` ×4 | 每只鼠的检测轨迹图（含阈值线/中性区/事件标注） | 直观展示算法工作原理，可放 PPT |
| `组间行为指标_PBS_vs_CNO.csv` + `图3_*.png` | CNO 组 vs PBS 组（次数/频率/总时长/潜伏期） | 1635 CNO 抬头频率 5.05 次/分 vs PBS 2.34/2.97；**n=2/组，试点性质，不能下统计结论** |
| `跨方法一致性_角度法vs坐标法.csv` | 角度法 vs y 坐标法帧级一致率与 κ | 帧级一致率 95.8–98.8%，κ 0.19–0.71；1631 低 κ 是因为该鼠几乎不垂直抬头（y 规则仅 9 帧），角度法仍能检出头部上仰——**角度法更灵敏** |
