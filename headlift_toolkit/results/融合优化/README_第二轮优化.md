## 做了什么

1. 俯仰角 winsor（2%–98%），减轻 DLC 跳点对 σ 的污染  
2. 规则网格：k∈[1.0,1.6] × band × min_dur，均带 30° 门控 → 规则天花板仍在 ~0.82  
3. RF LOMO 全视频概率 → 事件化 + **峰值抬升 ≥30°** → F1 抬到 **0.857–0.877**  
4. 并集/投票会把 FP 拉高，**不如纯 RF30 稳**

## 诚实边界

- 最优是在**同一金标准上选的**，存在乐观偏差；n=35 事件、4 鼠  
- RF 需训练与模型文件；规则法仍是零训练生产默认  
- **不改变**「n=2 不能写应用可靠」「需 n≥5 外部复验」两条红线  
- 1631/1635 仍弱 → 真正抬升要靠更干净的全长金标准 + 补样
