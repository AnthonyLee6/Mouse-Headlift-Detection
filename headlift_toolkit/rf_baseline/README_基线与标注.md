## 金标准验证结果速览（前 2 分钟窗口）

| 指标 | 结果 |
|---|---|
| 事件级（规则法 vs 人工） | P 0.50–1.00，R 0.57–0.89，F1 0.60–0.89（逐鼠见 CSV） |
| 事件 onset 误差 | 均值 0.35–0.66s（证明标注时间与 DLC 帧号对齐正确） |
| 帧级（规则法 vs 人工） | F1 0.39（召回仅 0.25——定义差：人工标整个 episode，系统只标阈值下核心段） |
| 帧级（RF-留一鼠） | **F1 0.64**（P 0.68 / R 0.61），显著优于规则法 |
| 帧级（GRU-留一鼠，序列基线） | F1 0.639（P 0.63 / R 0.65），与 RF 持平——小样本下深度时序无增益，支撑"可解释特征 + RF"的选型 |
| 事件级（RF 分段 vs 人工） | **计数层面规则法胜**：规则法 F1 0.75 vs RF 分段 0.63（RF 会把一段 episode 切碎成多次检出）；"计数用规则法、时长用 RF"的混合式结论成立（`事件级_RF分段vs人工.csv`） |
| 参数校准网格（k × 中性区 × 最短持续，40 组） | 默认参数 F1 0.75，网格最优 0.82（k=1.25），全网格 0.71–0.82 无悬崖（`参数校准_网格.csv` + 热力图；只可写"校准分析"，不可写"调参最优"，循环论证） |

漏检主因：状态机"必须回中性区"把连续两次抬头合并成一次（1635 的 0:27-0:28+0:29-0:30 等成对出现）；
多余检出主因：人工刻意排除的轻微抬头/抽动（1631 有 3 次）。两者都是论文可讨论的机制性发现，
前者还提示可调 neutral 参数做灵敏度分析。

## 你手上的两件事（优先）

1. **抽查誊录**（5 分钟）：`gold_抬头事件.csv` 的 40 条时间戳对照 PPT 原文核对一遍；
2. **关键点点击标注**（30–60 分钟，论文审稿缺口②"姿态模型评估"的最后一块）：
   ```bash
   python keypoint_gui.py --annotator 你的名字
   ```
   120 帧已抽好缓存（每鼠 30 帧：随机/低置信度/阈值附近/人工事件内/高角速度），
   按顺序点 鼻尖→头顶→左耳→右耳，点完自动下一帧，可中断续标；
   标完跑 `python keypoint_eval.py` → `../results/关键点评估/` 出逐 bodypart RMSE + 图。

## 你接下来要做的（按顺序）

> 以下为**可选的帧级精细标注流程**（金标准事件级验证已完成，见文首）；当需要更精细的
> 帧级边界、第二评分者 κ 或扩充 RF 训练集时再走。原三步中的"修订协议"已由 PPT 口径取代。

1. **先看 `预标注报告.md`**（1 分钟）——了解哪些帧两法一致（Enter 快进）、
   哪些不一致（96 帧，重点判断）；
2. **标注**（v2 GUI）：
   ```bash
   cd headlift_toolkit/rf_baseline
   python label_gui.py --annotator 你的名字            # 默认不一致帧优先队列
   python label_gui.py --annotator 你的名字 --order file  # 或按帧号顺序
   ```
   界面下方 ±0.5s 邻帧缩略图辅助判断运动方向，[p] 播放 ±0.75s 微片段（任意键停止），
   [Enter/Space] 接受规则法建议快进，[j] 跳到下一个不一致帧；实时保存，随时中断续标；
   第二个人用自己名字再标一遍即可算评分者间 κ；
   ⚠ 只标一部分帧时，方法评估必须用完整 680 帧或分层随机子集（优先级队列偏向困难帧）；
3. **训练与对比**（标注完成后一条命令）：
   ```bash
   python train_rf.py        # 输出 → ../results/rf_baseline/
   python shap_analysis.py
   ```
   注意 `labels/` 下出现 `labels_*.csv` 都会被合并；如做了双人标注，先仲裁分歧帧或告知我处理策略。

## 已跑出的真结果（`../results/`）

- `参数敏感性_阈值系数k.csv` + `参数敏感性_最短持续.csv` + `参数敏感性_扫描图.png`
- **诚实结论**（论文可直接引用，但注意措辞）：
  - 最短持续 0.05–0.15s 完全稳定（平台期），默认 0.15s 在稳定区内；
  - 阈值系数 k 无平台：计数随 k 单调下降（阈值即行为定义，属预期）；组间排序在
    k∈[1.0, 2.5] 全区间保持（1635 CNO 每个取值下都最高）。论文应写
    "绝对计数随定义变化、组间对比稳健"，**不要写"存在稳定平台"**。
