# 复现环境

Python >= 3.9（推荐 Python 3.11）

```bash
pip install -r requirements.txt
```

requirements.txt 覆盖 rf_baseline 全部脚本的运行依赖；DeepLabCut 本体不需要安装
（本工具包只消费 DLC 已生成的关键点 CSV，重训/补分析才需要 DLC 环境）。

脚本依赖关系（谁调用谁）：
```
headlift.py                 统一检测流水线（load_dlc_csv / head_angle / detect_lifts / cohen_kappa）
├── run_experiments.py       消融/稳健性/组间/一致性（比赛版产出，图1-图3）
├── features.py              22 维姿态特征
│   ├── sample_frames.py     抬头标注抽样+帧缓存（680 帧）
│   │   └── label_gui.py     抬头逐帧标注 GUI（可选，金标准 PPT 已覆盖）
│   ├── keypoint_sample.py   关键点评估抽样+帧缓存（120 帧）
│   │   └── keypoint_gui.py  关键点点击标注 GUI（待人工执行）
│   │       └── keypoint_eval.py  逐 bodypart RMSE 评估
│   ├── train_rf.py          RF 基线 vs 规则法（帧级，留一鼠CV）
│   │   └── shap_analysis.py SHAP 可解释性
│   ├── seq_baseline.py      GRU 序列基线（留一鼠CV，验证集须按连续时间段整块切分）
│   ├── draft_report.py      标注草稿统计报告（双法一致性）→ 预标注报告.md
│   ├── event_level_rf.py    RF 分段 → 事件级对比
│   └── validate_gold.py     人工金标准验证（事件级+帧级）
│       └── gold_calibration.py  参数校准网格（k × 中性区 × 最短持续）
└── param_sweep.py           参数敏感性扫描（无需标注）
```

随机性：所有脚本固定 seed=42（抽样/RF），重跑结果可复现。
